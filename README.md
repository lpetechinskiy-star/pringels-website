# Litenergles — «Гипербола вкуса»

Интерактивная кампания вымышленного бренда чипсов. Концепт для портфолио: бренд, персонажи и тексты выдуманы.

Механика построена на компоненте-референсе **Disc Cascade Carousel** (`src/components/ui/disc-cascade-carousel.tsx`):
наклонная линия объектов, которая поднимается к зрителю, две пружины (позиция и «отстающий» поворот/глубина/катание),
перетаскивание с инерцией и флик. Здесь вместо дисков — настоящие 3D-чипсы (гиперболический параболоид `z = x² − y²`) и банки.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/
npm run build:single # dist-single/index.html — всё в одном файле, можно просто открыть
```

Демо исходного компонента-референса: `/#disc-demo`.

Готовый сайт одним файлом: [`release/litenergles.html`](release/litenergles.html) — скачайте и откройте в браузере, интернет не нужен.

## Стек

Vite + React + TypeScript, Tailwind CSS v4 (структура shadcn: `components.json`, `@/components/ui`, `@/lib/utils`),
Three.js, GSAP + ScrollTrigger + SplitText, Lenis.

## Как устроено

```
src/
  components/ui/disc-cascade-carousel.tsx  референс (без изменений); его пружины и позы используются в 3D-сцене
  components/demo/                         демо референса
  components/site/                         навигация, обёртка сцены, 10 сцен
  experience/
    stage.ts       два прозрачных WebGL-холста: под текстом и над ним — чипсы пролетают сквозь типографику
    chip.ts        геометрия чипса, процедурные текстуры, шейдер приправы (цвет вкуса на каждом чипсе)
    can.ts         банка и генерируемая этикетка для каждого вкуса
    formations.ts  «формации» — где должен быть каждый чипс в каждой сцене как функция прогресса скролла
    director.ts    смешивание формаций между сценами, пружины, слои, жесты, цвет фона
    physics.ts     лёгкая 2D-физика для сцены «Гравитация»
    store.ts       общее состояние для React и WebGL
  data/            вкусы и главы
```

Скролл задаёт цель для каждого чипса, пружины решают, как он туда долетит, — поэтому всё движение
физичное, но полностью управляется прокруткой. Между сценами чипсы летят по дугам с вращением.

## Сцены

0. **Поток** — столбик чипсов выстреливает и рассыпается в бесконечный каскад (механика референса). Тяни/свайпай.
1. **Полёт** — туннель из чипсов, текст подсвечивается по словам.
2. **Форма** — один огромный чипс в трёх ракурсах, остальные на орбите.
3. **Стопка** — чипсы по дугам укладываются в стопку, счётчик.
4. **Состав** — наклонное кольцо проходит перед словами и за ними.
5. **Вкусы** — каскад банок как в референсе; выбор вкуса перекрашивает мир и приправу на всех чипсах.
6. **История** — горизонтальная лента, чипсы катятся по полу как колёса.
7. **Гравитация** — физика: хватай, бросай, тап — подбросить всё.
8. **Башни** — чипсы падают с неба в башни сообщества.
9. **Финал** — чипсы возвращаются в банку выбранного вкуса; её можно крутить и открыть.

## Доступность и производительность

- `prefers-reduced-motion` и переключатель «Меньше движения» в меню.
- У каждого жеста есть кнопка и клавиатурная альтернатива (стрелки, радиогруппа вкусов, «Встряхнуть», «Открыть банку»).
- Только transform/opacity в DOM-анимациях; чипсы — один `InstancedMesh` на слой; слой не рендерится, если пуст.
- Меньше чипсов и ниже детализация на телефонах и слабых устройствах; DPR ограничен.

## Ассеты

Фотографии банок из брифа использованы только как референс линейки вкусов и цветов: на них реальный бренд
и водяные знаки стоков, поэтому в проект они не встраиваются. Все чипсы, банки, этикетки и маскот нарисованы кодом.
